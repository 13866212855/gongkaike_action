# 数字信息鉴别师工作站（gongkaike）

高一信息技术公开课《1.3 信息及其特征》随堂互动实验平台——**“校园数字信息鉴别师行动”**。

---

## 一、应用功能概览

本平台专为高一信息技术 40 分钟课堂设计（支持 4 人一组的机房协同探究及教室大屏投影展示），无需登录、即开即用，包含以下核心模块：

1. **【任务一·问诊】时空罗盘（探究信息价值的相对性与时效性）**
   - 围绕“中考改革突发调整”情境快讯，支持勾选 `👨‍🎓 高一学生`、`👨‍👩‍👧 初三学生及家长`、`🏫 教育机构/培训机构` 三类受众进行多曲线叠加对比。
   - 提供从 `现在（3月）` 到 `中考结束（6月下旬）`、`中考后一个月（7月）` 的 6 节点水平滑块与一键自动推演，直观展示越过“⚠️ 中考结束”关键分界线后初三考生群体的信息价值断崖式归零现象。
   - 内置结论填空、快捷思考词条以及供教师点评使用的隐藏式“查看参考答案”面板。

2. **【任务二·解剖】多维解剖台（探究信息的真伪性）**
   - 左右分栏对照展示【信息A·权威来源（省气象台快讯）】与【信息B·网络热传（夸张自媒体快讯）】，同时支持一键切换“中考改革政策对比”或课堂实时自定义编辑文本。
   - 点击 **“🔬 开始解剖”** 后依次激活动画展示：
     - **模块A（语文之眼 —— 分词情绪热力图）**：红色大字高亮情绪化/夸张词汇，灰色小字展示普通客观词汇，点击高亮词可查看造谣修辞诊断。
     - **模块B（数学与科学之尺 —— 极值与逻辑核查）**：将夸张数据与官方预报、历史极值横向比对，剖析三大逻辑谬误。
     - **模块C（信源与社会之镜 —— 溯源链与破绽打卡）**：对比三级权威审核链与流量收割链，支持小组互动勾选破绽证据。

3. **【任务三·建构】特征体系图谱与鉴别宣言**
   - 统整《1.3 信息及其特征》五大核心特征（载体依附性、价值相对性、时效性、共享性、真伪性），提供 5 个校园真实情境对号入座互动挑战、核心概念填空及小组鉴别宣言签署。

4. **本地防丢存储与【导出本组探究报告】**
   - 所有答题记录按右上角输入的 **“第 __ 小组”** 编号实时自动保存至浏览器 `localStorage`，刷新页面不丢失。
   - 底部全局固定 **“导出本组探究报告”** 按钮，支持一键打印/导出 PDF、复制报告文本或下载 `.txt` 存档文件。

## 二、本地开发与运行

```bash
# 1. 安装依赖
npm install --legacy-peer-deps

# 2. 启动开发服务器（默认监听 http://localhost:3000）
npm run dev

# 3. 编译生产版本并启动生产服务
npm run build
npm run start
```

## 三、Docker 容器化与一键部署说明（myusellm 规范）

- **镜像名称 / 容器名称**：`gongkaike`
- **宿主机对外端口**：`7874`（容器内部端口：`3000`）
- **本地数据持久化目录**：`D:\docker\gongkaike\data`
- **远程服务器数据目录**：`/bak/docker/gongkaike/data`（目标服务器：`172.29.173.42:7874`）

### 重要注意事项
1. **多阶段构建与锁文件精确安装**：
   `Dockerfile` 采用多阶段构建方案，依赖严格按照 `package-lock.json` 通过 `npm ci --legacy-peer-deps` 精确安装，内置国内镜像源与 3 次自动重试机制。
2. **刷新依赖锁文件**：
   若修改过 `package.json` 或删除过 `package-lock.json`，**必须**先在项目根目录执行以下命令重新生成锁文件（必须带 `--legacy-peer-deps`），然后再运行部署脚本：
   ```bash
   npm install --legacy-peer-deps --package-lock-only
   ```
3. **一键部署脚本**：
   - **本地 Windows Docker Desktop 部署**：直接双击或命令行运行 `redeploy.bat`，构建并启动后访问 `http://localhost:7874`。
   - **远程 Linux 服务器一键部署**：运行 `upload2remote.bat`，自动完成本地构建、导出 tar 包、SCP 上传至 `172.29.173.42` 并启动远程容器。
